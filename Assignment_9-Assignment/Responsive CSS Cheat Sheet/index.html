Responsive CSS Cheat Sheet

Key concepts for building adaptive layouts.

Media Queries

@media (max-width: 700px) { ... }

The fundamental RWD tool. Applies styles based on device characteristics like screen width.

Fluid Layouts

width: 100%; / max-width: 100%;

Using relative units (%, vw) ensures containers expand and contract with the viewport.

Flexbox

display: flex; flex-wrap: wrap;

Ideal for arranging small groups of items, distributing space, and easy vertical centering.

CSS Grid

grid-template-columns: 1fr 1fr;

Designed for two-dimensional layout control, perfect for defining major page areas.

Responsive Images

max-width: 100%; height: auto;

Ensures images never exceed their container size, preventing horizontal scrolling.

Typography

font-size: clamp(1rem, 3vw, 2rem);

Using relative units (em, rem) and clamp() to ensure text readability across sizes.
